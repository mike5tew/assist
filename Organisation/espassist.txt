## Project Context: ESP Organizer - Educational Skills Semantic Database

**Core Mission:** To develop a semantic search system for educational skills that enables AI-assisted understanding of skill relationships and dependencies. Our focus is on creating a robust foundation for educational technology that can support adaptive learning and skill development tracking.

**Current Development Status:**
* **Working MVP:** Functional Go API with MongoDB and Weaviate integration
* **Semantic Search:** Deterministic embedding generation for skill matching (ready for LLM upgrade)  
* **Skills Database:** 62 educational skills with hierarchical relationships and assessment criteria
* **Vector Storage:** Weaviate integration with working semantic queries
* **Testing Framework:** Comprehensive CLI tools for debugging and quality analysis

---

## Data Strategy for Educational Skills

**Core Principle:** Leverage MongoDB for comprehensive skill data management and Weaviate for efficient semantic search and relationship discovery.

### A. MongoDB: The Source of Truth
* **Content:** Complete skill definitions (name, description, 5-level criteria), source references, and explicit parent-child relationships.
* **Role:** CRUD operations, structured queries, data integrity, and relationship management.

### B. Weaviate: The Semantic Understanding Layer  
* **Content:** Vector embeddings of skill descriptions and criteria for semantic similarity matching.
* **Metadata:** Each vector includes MongoDB `_id` for retrieval and skill metadata for filtering.
* **Role:** Fast semantic search ("find skills like X"), relationship discovery, and LLM query preparation.

### C. LLM Integration (Future)
* **Current:** Deterministic embedding generation for consistent testing
* **Planned:** Integration with actual LLM APIs for production embedding generation
* **Architecture:** Ready for drop-in replacement of dummy embeddings with real LLM calls

---

## Technical Architecture Patterns:

* **Microservices:** Clean separation between API, database layers, and vector search
* **Service Pattern:** Skills service handles MongoDB operations, query handler coordinates semantic search
* **Error Handling:** Comprehensive error handling across all service boundaries  
* **Testing:** CLI utilities for system verification and quality analysis
* **Docker Ready:** Full containerization with development and production configurations

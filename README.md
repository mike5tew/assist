# Smart Minds: Research & Strategy (assist)

This repository serves as the **Research & Development Hub** for the Smart Minds project. It contains high-level strategy, blueprints, and proof-of-concept logic for the HumanOS and CHISG ecosystems.

## Content
- **`docs/`**: Strategic playbooks, technical architecture, and decision logs.
- **`blueprints/`**: The original 131-skill CHISG taxonomy and behavioral spectrum definitions.
- **`tools/`**: Internal scripts for semantic link extraction and data processing.

## Current Architecture Status
- **Development Platform**: Shifted to `ESPProj` (Enterprise backend).
- **Mobile Prototype**: Shifted to `SkillsMarkbookMobile` (React Native app).
- **Protocol**: Logic developed here is migrated to `ESPProj` once validated.

---
*Note: This is not a production environment. Production-ready Go services are maintained in `ESPProj/espdata/api`.*

## Integrity Check Patterns (Triangulation)

To validate a "Teaching Analog" (e.g., comparing a student's lack of resilience to a bimetallic strip's physical limits), the CHISG engine will look for the following density:

1.  **Direct Path Count**: How many skills map to this spectrum? 
    *   *Constraint*: If a spectrum maps to >3 unrelated skills, it is flagged as "Semantic Overlap" and requires deconstruction.
2.  **Cross-Domain Intersection**: Does "Self-regulation" appear in both "Emotional" and "Social" circuits?
    *   *Verification*: Yes, linking it to the `circuit:voltage-regulation` node in the global KG.
3.  **Source Density**: Links tagged with `source:neuro-science` have higher weight than `source:expert-heuristic` in the "Smart Minds" reasoning layer.

# SkillsMarkBook Sticker Album - Quick Reference

## What Is It?

A physical + digital reward system where teachers award stickers to students when they demonstrate key skills. Students collect stickers in an A5 album over time, creating a tangible portfolio of growth.

**Physical Component**: A5 printed album with 8 skill area pages  
**Digital Component**: Mobile app tracking + export/print functionality  
**Reward**: Custom sticker (5cm×5cm) placed in album by student  

## Why Now?

- Makes abstract "Skills Map" concrete and motivating
- Works as a bridge between traditional (paper) and digital (app-based) systems
- Proven psychology: collections motivate more than dashboards
- Low cost (~£2-3 per student per year)
- Supports multiple neurodivergent learning styles

## Key Features

### For Teachers
✅ "Award Sticker" button in Skills Markbook Mobile (one-click action)  
✅ Batch print queue (print all stickers at end of day)  
✅ Analytics dashboard (which skills are being demonstrated?)  
✅ Fairness check (are stickers distributed equitably?)  

### For Students
✅ "My Album" tab showing collected stickers  
✅ Progress bar per skill area ("3 of 5 stickers")  
✅ Celebratory notifications when earning stickers  
✅ QR code to digital profile with observations  

### For Parents
✅ Digital link to child's album progress  
✅ Print & display at home  
✅ Leave encouraging comments  

## The 8 Core Skill Areas

1. **Communication** - Express clearly, listen, ask questions
2. **Problem Solving** - Break down challenges, persist, try approaches
3. **Creativity** - Generate ideas, make connections, innovate
4. **Resilience** - Bounce back, ask for help, learn from failure
5. **Collaboration** - Work with others, support, share
6. **Leadership** - Take initiative, encourage, take responsibility
7. **Research** - Find & organize information, ask good questions
8. **Critical Thinking** - Ask "why?", examine evidence, reason

## Questions?

- **How is this different from gamification?** It's not about points or leaderboards—it's about creating a physical artifact (the album) that students own and keep, which has proven higher emotional resonance.
- **Doesn't printing stickers create waste?** The cost is minimal (~£0.50/term) and the album becomes a keepsake. Optional: use digital-only version for sustainability.
- **What if sticker inflation happens?** Clear rubrics + teacher training + admin dashboard alerts prevent this. Phase 2 includes tier levels (Bronze/Silver/Gold) for progression.
- **Can this work for secondary school?** Yes—adjust skill areas and marketing (call it "Skill Collector" instead of sticker album). Different design aesthetic for older students.

# Part Three: Skills Map Integration

## Existing Skills Map Nodes Relevant To This Section

| Skill | Location | Relevance |
| :--- | :--- | :--- |
| **Responsibility Threshold** | ETP Spectrum | The slider for deflecting vs absorbing blame. Central to the "where does responsibility begin" question. |
| **Consequence Anticipation** | ETP Spectrum (under Risk Tolerance) | The skill beneath choice. You cannot choose well if you cannot simulate the outcome. |
| **Risk Tolerance** | ETP Spectrum | How you price the unknown. The gateway to practising choice. |
| **Integrity Logic** | ETP Spectrum | How you process rules and exceptions. The "401 rule" lives here. |
| **Agency Threshold** | ETP Spectrum | How much choice feels available to you. The scaffold is designed to expand this. |
| **Goal-Directed Persistence** | Skills Map (Self) | The capacity to maintain effort toward a chosen outcome. Trained by the pathway. |
| **Self-Assessment** | Skills Map (Self) | Required for "did this choice work?" feedback loop. |
| **Feedback Seeking** | Skills Map (Communication) | Required for iteration. The child must learn to ask "how did I do?" |
| **Negotiation** | Skills Map (People) | Required for team-based choices (D&D, projects, DofE expeditions). |

## New Skills Map Nodes Suggested By This Section

| New Skill | Domain | Description |
| :--- | :--- | :--- |
| **Choice Rehearsal** | Self | The ability to practise making decisions in low-stakes environments. Distinct from decision-making under real pressure. |
| **Scaffold Recognition** | Metacognitive | The ability to recognise what level of support you currently need. "I need a CYOA today, not a DofE expedition." |
| **Consequence Triage** | Problem Solving | The ability to distinguish between consequences that are catastrophic, uncomfortable, or trivial. Trained by escalating the pathway. |

# Part Four: ETP Framework Additions

## New ETP Spectra Suggested By This Section

| Spectrum | Pole A | Pole B | Description |
| :--- | :--- | :--- | :--- |
| **Agency Threshold** | Low Agency | High Agency | How much choice feels available to you. Not how much choice actually exists. The scaffold expands perceived agency. |
| **Consequence Tolerance** | Consequence-Averse | Consequence-Seeking | How you respond to the possibility of negative outcomes. Distinct from Risk Tolerance (which is about uncertainty). This is about known downsides. |

## Existing ETP Spectra That Ground This Section

| Spectrum | Role In The Pathway |
| :--- | :--- |
| **Risk Tolerance** | The CYOA stage trains low-risk choice. The DofE stage tests high-risk choice. |
| **Integrity Logic** | The "401 rule" is an absolutist framing. The pathway teaches relativist calibration. |
| **Responsibility Threshold** | The central spectrum for the "where does responsibility begin" question. |
| **Current Load** | Determines what level of the pathway is appropriate today. High load → CYOA. Low load → DofE. |
| **Threat Response** | The pathway must be calibrated so the threat response is not triggered. The scaffold keeps the voltage low enough to practise. |

# Part Five: Sentences That Must Not Change

> *"The person you are speaking to is not one voice. They are a negotiation between poles. The question is not which voice is right. The question is whether you can hear both."*

> *"If you have the opportunity then you have the responsibility."* (The 401 Rule)

> *"Responsibility begins where reading the dashboard becomes possible. Not at the point of perfection. At the point of awareness."*

> *"You cannot teach someone to choose by telling them to choose. You build a scaffold. CYOA with parents. D&D with friends. Civilisation builders. Small projects. Then the DofE. Each stage is a simulator. The stakes rise. The scaffold fades. By the time they face a real choice, they have practised. Not fearlessly. Skilfully."*

> *"The DofE is the expedition. Your framework is the compass. Together, they are the difference between getting lost and knowing how to navigate."*

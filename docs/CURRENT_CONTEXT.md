## Production 502 — assist-api Weaviate Unreachable (2026-05-23)

### Symptom
GET /api/chisg/papers returned 502. 
assist-api logs showed: connection refused to weaviate:8080

### Root Cause
assist-api container was only on `esp-thinking_shared-network`.
Weaviate container runs on `esp_shared-network` (the legacy network from the 
`/opt/esp/` stack). assist-api could not resolve the `weaviate` hostname.

### Live Fix
```bash
docker network connect esp_shared-network assist-api
```
Immediately resolved without restart.

### NTM Extraction — context field architecture decision (2026-05-/06)
_Path: CHISG > NTM Pipeline > Extraction > Context Field_

DECISION: The 'context' field in AcademicLink must encode TWO things, not one:
1. EXPERIMENT IDENTITY (for reproducibility): assay type + figure/panel reference
   e.g. "survival assay Fig. 3B", "qRT-PCR Fig. 4C", "RNA-seq experiment"
2. CONDITIONS: organism/strain, experimental state, scope, key qualifiers
   e.g. "M. smegmatis mc2155 under starvation conditions", "M. tuberculosis H37Rv in vitro"

Combined format (max 150 chars): "survival assay Fig. 3B; M. smegmatis mc2155 under starvation"
